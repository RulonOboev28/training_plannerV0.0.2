# История изменений

## [0.0.2-dev] — 2026-10-13 (снимок для GitHub)

Рабочая версия перед сайтом для спортсменов (roadmap, пункт 1 выполнен).

### UX и полотно

- Память навигации: подсветка контейнера при «Вверх», фокус при входе из календаря.
- Авто-расстановка колонками; стрелки `auto_down` / `auto_wrap` (после ручного сдвига плиток — прежние дуги `sequence`).
- Связи: Shift+ЛКМ (источник), Shift+ПКМ (цель); Ctrl+ЛКМ — множественный выбор.
- Панель фильтров при выделении нескольких плиток; исправлен ввод в «Свойства» (без сброса фокуса).
- Журнал действий (25 записей, даты из календаря плана) и откат до выбранного шага в «История».

### Библиотека

- Коллекции шаблонов, дерево с перетаскиванием, диалог сохранения в библиотеку.

### Модель для сайта (пункт 1 roadmap)

- `AthleteProfile`, `TrainingPlan.athletes`, назначение упражнений/тренировок (`assigned_to_all`, `assigned_athlete_ids`).
- `exercises_for_athlete()`; обратная совместимость старых `.tplan`.

### Тесты

- navigation, auto_layout, connections, action_journal, history_rollback, library_store, athlete_assignments.

## [0.0.2] — 2026-06-24

Полнофункциональный конструктор тренировочного плана с демо-данными, сборкой exe и распределением нагрузки по уровням.

### Новые возможности

- **Иерархия 6 уровней**: упражнение → тренировка → микроцикл → мезоцикл → макроцикл → годичный план.
- **Визуальное полотно**: масштабирование, панорамирование, стрелки-связи, авто-расстановка, undo/redo.
- **Библиотека и пресеты** упражнений, циклов и тренировок; сохранение своих шаблонов.
- **Импорт/экспорт плана** в формате `.tplan` (JSON).
- **Экспорт** полотна в PNG/PDF и таблицы в CSV.
- **Автосохранение** и история версий с восстановлением.
- **Сводка нагрузки** на каждом уровне:
  - итого (время, км, число упражнений);
  - распределение по дочерним элементам (тренировки, микроциклы и т.д.);
  - разбивка по видам нагрузки (роллеры · классика, бег, вело, ОФП…);
  - разбивка по типам упражнений.
- **Демо-план** `demo/mesocycle_obem_skorost_tehnika.tplan` — мезоцикл лыжных гонок на 4 недели (28 тренировок).
- **Сборка Windows exe** без установки Python (`scripts/build_release.ps1`, PyInstaller).
- **Руководство пользователя** для конечных пользователей exe.

### Улучшения интерфейса

- Кнопка **«Открыть»** сразу предлагает выбор `.tplan` с диска (не только внутренние сохранения).
- Кнопки библиотеки переименованы в **«Импорт/Экспорт шаблонов»** (JSON), чтобы не путать с импортом плана.
- Тёмная и светлая темы, три размера плиток, привязка к сетке.

### Техническое

- Модуль `core/paths.py` — корректные пути к ресурсам в собранном exe.
- Модуль `core/aggregates.py` — расчёт сводной статистики.
- Тесты: навигация, геометрия, экспорт, агрегаты (22 теста).
- Скрипт `scripts/generate_demo_mesocycle_tplan.py` — генерация демо-плана с объёмами в км.

### По сравнению с v0.0.1

| v0.0.1 | v0.0.2 |
|--------|--------|
| Только библиотека элементов | Полный конструктор с иерархией и полотном |
| Без параметров упражнений | Длительность, км, пульс, подходы, инвентарь |
| Без сохранения планов | `.tplan`, автосохранение, история |
| Без демо-данных | Готовый мезоцикл на месяц |
| Без exe | Портативная сборка для Windows |
| Без сводки нагрузки | Распределение по уровням и видам работы |
