# Конструктор тренировочного плана

Визуальный конструктор тренировочного процесса: от упражнения до годичного цикла.

## Запуск

1. Откройте папку с программой.
2. Запустите **`TrainingPlanConstructor.exe`** двойным щелчком.
3. Python и дополнительные программы **не нужны**.

## Демо-план

В папке **`demo`** лежит пример мезоцикла для лыжных гонок:

- `mesocycle_obem_skorost_tehnika.tplan`

Как открыть: **Открыть** → выберите этот файл (или укажите путь к `demo`).

## Основные действия

| Кнопка | Назначение |
| --- | --- |
| **Новый** | Пустой план |
| **Открыть** | Загрузить `.tplan` с диска или из сохранённых |
| **Сохранить** | Сохранить план во внутреннее хранилище |
| **Экспорт ▾** | Экспорт `.tplan`, PNG, PDF, CSV |

Данные (автосохранение, библиотека, сохранённые планы) хранятся в:

`C:\Users\<имя>\.training_constructor\`

## Управление на полотне

| Действие | Как |
| --- | --- |
| Масштаб / смена уровня | Ctrl + колёсико мыши |
| Прокрутка | колёсико мыши |
| Панорама | средняя кнопка мыши |
| Войти внутрь плитки | двойной щелчок |
| Копировать / Вставить | Ctrl+C / Ctrl+V |
| Отмена / Повтор | Ctrl+Z / Ctrl+Y |

## Библиотека (слева)

- **Пресеты** — готовые шаблоны упражнений и циклов.
- **Импорт шаблонов** — только JSON-шаблоны (не `.tplan`).
- Чтобы открыть **целый план**, используйте кнопку **Открыть** вверху.

## Системные требования

- Windows 10/11 (64-bit)
- Разрешение экрана от 1280×720
