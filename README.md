# Конструктор тренировочного плана

**Версия 0.0.2** — визуальный иерархический конструктор тренировочного процесса: от отдельного
упражнения до годичного цикла. Не дневник выполненных тренировок, а инструмент
для **проектирования** будущего плана.

> Предыдущая версия: [training_plannerV0.0.1](https://github.com/RulonOboev28/training_plannerV0.0.1)  
> Список изменений: [CHANGELOG.md](CHANGELOG.md)
## Идея

Масштабируемое полотно (как Google Maps): отдаляя масштаб, вы видите годичный
цикл; приближая — конкретное упражнение с параметрами. 6 уровней иерархии:

1. Упражнение
2. Тренировка
3. Микроцикл
4. Мезоцикл
5. Макроцикл
6. Годичный план

На каждом уровне вы работаете с плитками одного типа и соединяете их стрелками.
При отдалении дочерние элементы сворачиваются в одну плитку родителя, при
приближении — родитель раскрывается, показывая вложенные элементы.

## Возможности

- Тёмная и светлая темы (переключаются в тулбаре).
- Три зоны: библиотека (слева), полотно (центр), свойства (справа).
- Точечная сетка с мягким примагничиванием; плитки не накладываются друг на друга.
- Границы области (тренировки/цикла) растягиваются под содержимое во все стороны.
- Плавные дугообразные стрелки-связи (выходят из правого края, а для элементов
  «друг над другом» — из верхнего/нижнего).
- Плавные анимированные переходы между уровнями с запоминанием положения камеры.
- Множественное выделение (рамкой/Shift), групповое перемещение.
- Копирование/вставка/дублирование, авто-расстановка, контекстное меню (ПКМ).
- Отмена/Повтор (Undo/Redo) для всех действий.
- Сводная статистика по вложенным элементам в панели свойств.
- Регулируемый размер плиток (компактные / обычные / крупные).
- Экспорт: план `.tplan`, полотно в **PNG**/**PDF**, таблица в **CSV**.
- Автосохранение + история версий с восстановлением.

## Управление

| Действие | Как |
| --- | --- |
| Прокрутка по времени | колесо мыши |
| Масштаб / смена уровня | Ctrl + колесо мыши |
| Панорамирование | перетаскивание средней кнопкой мыши |
| Выбор / перемещение плитки | ЛКМ |
| Выделить несколько | ЛКМ-рамка по пустому месту / Shift+клик |
| Контекстное меню | ПКМ |
| Создать стрелку | ПКМ → «Создать связь отсюда» → ПКМ по цели → «Связать сюда» |
| Войти внутрь плитки | двойной клик |
| Копировать / Вставить / Дублировать | Ctrl+C / Ctrl+V / Ctrl+D |
| Отмена / Повтор | Ctrl+Z / Ctrl+Y (или Ctrl+Shift+Z) |
| Выделить всё | Ctrl+A |
| Авто-расстановка | Ctrl+L |
| Удалить | Delete |
| Отмена выбора источника связи | Esc |

## Демо-план

В папке [`demo/`](demo/) — пример мезоцикла для лыжных гонок (4 недели, 28 тренировок).
Откройте `demo/mesocycle_obem_skorost_tehnika.tplan` через **Открыть** в приложении.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Сборка exe (Windows)

Портативная папка с exe, темами, README и демо-планом — Python на целевом ПК не нужен.

```powershell
.\scripts\build_release.ps1
```

Результат: `dist/TrainingPlanConstructor/`

- `TrainingPlanConstructor.exe` — приложение (окно называется «Конструктор тренировочного плана»)
- `README.md`, `Руководство_пользователя.md` — документация
- `demo/mesocycle_obem_skorost_tehnika.tplan` — пример плана

Требуется Python 3.10+ только на машине **разработчика** для сборки.
